How this works

  1. Your inputs are engineered into the same 19 features the model was trained on.
  2. The calibrated logistic regression model outputs a probability of default (PD).
  3. If PD is below the validated threshold (0.430), the application is approved.
  4. If declined, SHAP identifies the drivers, mapped through an approved reason-code taxonomy — never raw model internals.
